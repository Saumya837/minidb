chore(tests): scaffold the automated test harness

Add the file layout for the parser regression suite. The files are
empty stubs; behavior comes in later commits.

- tests/harness/: tree_dump, case_loader, case_runner, failure_log,
  test_statistics (one job per file)
- tests/run_tests.cpp: entry point
- tests/cases/: one .cases file per statement group
- tests/logs/: failure logs (generated, ignored) and test_statistics.log
  (tracked)
- .gitignore: tests/logs/failures_*.log

Design: each case is a query plus an expected tree or error message,
compared line by line; failures do not stop the run and are written to
a per-run log with the case number and reason.
